# CVtrl

Marre de devoir **Ctrl+C** **Ctrl+V** des caractères spéciaux non-présents sur le clavier depuis le web à chaque fois ? Cette application mobile va résoudre ce problème, tous les caractères spéciaux les plus courants sont rassemblés sur une seule interface, et vous pouvez les copier dans le presse-papiers en un clic.

---

Application réalisée à l'aide de React Native + Expo. Codée à l'aide de l'IA pour que je puisse me familiariser avec le développement et le déploiement d'applications front-end sans devoir passer des heures sur les documentations en ligne.

### Démarrer

1. Installer les dépendances

   ```bash
   npm install
   ```

2. Lancer l'application sur localhost

   ```bash
   npx expo start
   ```
